# Hostel/PG Management & Complaint Tracking System

A professional, database-driven management system designed for residents and wardens.

## Features
- **Student Dashboard**: Room registration, fee status, complaint logging.
- **Admin Dashboard**: Student management, room allocation, staff assignment, complaint resolution.
- **Real-time Tracking**: Monitor complaint status and room occupancy.
- **Reporting**: Generate reports on payments and pending tasks.

## Tech Stack
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Database**: Relational Database (MySQL/PostgreSQL)

## Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`
3. Set up the database using `backend/database.sql`.
4. Start the server: `node backend/server.js`
